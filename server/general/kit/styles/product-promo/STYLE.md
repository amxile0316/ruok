# 产品宣传片 · Product Promo — Style Prompt

> 一支 15–30 秒的产品片：铜绿的结构、青铜的一击、留白的呼吸。
> 画面只由排版、几何与光构成，不依赖实拍素材；产品本身用「参数化构图」表达（盘面、环形光、数据条），
> 需要真实产品图时，把用户素材复制进 `assets/` 再用 `<img>` 引用。

Suits films of 15–30 s.

## 1. 本质 / 不是什么

- **一条片只讲一个卖点。** 开场给钩子，随后依次是：特写、功能演示、转场、CTA。每一段只承担一件事。
- **产品是主角，不是背景。** 产品用几何盘面 + 光代表，文案围绕它转；不堆 UI 截图、不铺满屏幕。
- **克制的颜色。** 深铜绿作底，铜绿作结构，青铜只给「要人行动」的那一下（主按钮、关键数字、播放头）。
- **可拆的镜头。** 每个镜头是一个独立子页面（`compositions/*.html`），用户在时间线上能单独挪、删、改。
- **不是** keynote 式大段文字动画（字太多）、不是霓虹 HUD（发光线条堆叠）、也不是套模板的「文字飞入 + 粒子」。

## 2. 视觉系统（沿用 RUOK 设计令牌）

影片页面是独立文档，拿不到宿主的 CSS 变量，**直接写令牌的十六进制值**；它们与 `src/workspace/ruok-theme.css` 一一对应。

| 令牌 | 值 | 用途 |
|---|---|---|
| `patina-900` | `#0c1211` | 画布底色 |
| `patina-800` | `#131d1b` | 卡片、面板 |
| `patina-700` | `#172421` | 次级面板、轨道 |
| `patina-600` | `#1f2e2a` | 分隔、网格 |
| `verdigris-500` | `#4f8f80` | 结构线、扫描光、进度 |
| `verdigris-300` | `#6fb3a2` | 次级高亮、标签 |
| `bronze-300` | `#d6a85f` | 主行动 / 选中 / 关键数字 |
| `bronze-200` | `#e6c489` | 主行动高光 |
| `bronze-700` | `#8a6534` | 铜的暗部、描边 |
| `ink` | `#eef4f0` | 主文字 |
| `ink-2` | `#c7d3ce` | 次文字 |

造型规则与界面一致：

- **圆角四档**：`6px`（标签）、`10px`（卡片）、`14px`（面板）、`999px`（药丸按钮 / 圆盘）。
- **1px 发丝线** + 顶部内侧 1px 高光；阴影两层（近处 1px 硬边 + 远处大模糊）。
- **线宽 1.6px** 用于图标与结构线；发光只用一层柔光，不叠三层霓虹。
- **网格**：64px 细网格（`#1f2e2a`，8% 透明），只在需要「工程感」的镜头出现。

## 3. 字体与字幕

- 标题：`Noto Serif SC`（正文回退 `PingFang SC` / `Microsoft YaHei`），字重 600，字号为画宽的 6–9%。
- 正文与标签：`Noto Sans SC`，标签字号 2.4–3%，字距 `0.06em`，全大写英文标签用 2.2%。
- 数字：等宽感，铜色，配一个极小的单位（`×`、`ms`、`%`）。
- **字幕放在画面下三分之一的安全区内**（标题安全区 80%），一行不超过 18 个汉字；每句一个 `.clip`，
  带 `data-start` / `data-duration`，入场用 CSS `animation`，不要脚本生成。
- 标题与字幕不叠在同一位置：标题在上三分之一，字幕在下三分之一。

## 4. 镜头配方（可复用分镜片段）

五条最小闭环配方。每条都可以单独使用；字段 `时长为推荐区间`，`参数` 是模板里可直接改的值。

| # | 配方 | 用途 | 时长 | 可调参数 |
|---|---|---|---|---|
| 1 | `opening-hook` 开场钩子 | 用一句反常识的话抓住注意力，抛出产品名 | 3–4 s | `kicker`、`headline`（两行）、`accent`、`scanSpeed` |
| 2 | `product-closeup` 产品特写 | 只讲一个特征：环形光扫过产品盘面 | 3–5 s | `product`、`tagline`、`ringSize`、`sweepAngle` |
| 3 | `feature-demo` 功能演示 | 2–3 个功能点逐条点亮，形成节奏 | 4–6 s | `steps[]`（每条一个短句）、`stepGap`、`progress` |
| 4 | `transition-wipe` 转场 | 斜切色带把两段接起来，顺带报一个数字 | 1.5–2 s | `label`、`angle`、`direction`、`bandColor` |
| 5 | `closing-cta` 结尾 CTA | 品牌锁标 + 一个动作 + 一个网址 | 4–5 s | `brand`、`cta`、`url`、`halo` |

### 4.1 开场钩子 `opening-hook`

- **做什么**：顶部一行小标签淡入（`kicker`），两行大标题自下而上错开 120ms 进入；一条铜绿扫描线从左到右掠过，
  扫过之后标题从 `ink-2` 变成 `ink`。
- **为什么先它**：第一秒决定留存；钩子句要具体（「把 3 小时的片子压成 20 秒」），不要形容词堆叠。
- **可调**：`--scan-speed`（默认 1.2s）、标题字号（默认 0.088 × 画宽）、`accent` 词用铜色高亮（只高亮一个词）。
- **忌**：整段不要超过 4 秒；不要同时出现三条以上信息。

### 4.2 产品特写 `product-closeup`

- **做什么**：画面中心一个 `--ring-size` 的圆盘（默认 420px），铜色 1px 描边 + 铜绿内环；
  一道锥形光以 `--sweep-angle` 扫过；产品名在中轴下方，一句 tagline 紧随其后。
- **为什么**：特写建立「这是什么东西」，只讲一个特征，不列参数。
- **可调**：`--ring-size`、`--sweep-angle`（默认 24deg）、`--sweep-duration`（默认 1.6s）、盘面里的符号。
- **有真实产品图时**：把图放进 `assets/`，替换 `.plate` 里的几何占位（保持 1:1 或 4:3 遮罩和同一描边）。

### 4.3 功能演示 `feature-demo`

- **做什么**：左对齐三行「步骤卡」，每行由一个编号、一句功能、一条进度条组成；按 `--i` 每 220ms 依次点亮，
  进度条从 0 长到 `--fill`。已点亮的行图标变铜色，未点亮保持 `ink-2`。
- **为什么**：把「能做什么」拆成可数的 2–3 条，观众才记得住；超过 3 条就拆成两个镜头。
- **可调**：`steps[]` 文本、`--step-gap`、`--fill`（默认 72%）、是否显示进度条。
- **忌**：别在这里放长句；每行不超过 12 个汉字。

### 4.4 转场 `transition-wipe`

- **做什么**：一条 `--angle`（默认 -12deg）的铜绿斜带从一侧扫入再扫出，带中央压一个数字标签（`label`，
  例如「02 / 03」或「3× 更快」）。
- **为什么**：给一个明确的节奏断点，同时用数字承接上下两段。
- **可调**：`--angle`、`direction`（`ltr` / `rtl`）、`--band` 宽度、`label`。
- **忌**：不要用溶解或缩放转场；斜切只切一次，不做来回抖。

### 4.5 结尾 CTA `closing-cta`

- **做什么**：品牌锁标（问号圆盘）落位，下方一句 CTA，青铜药丸按钮带一层柔光呼吸（2 次，有限）；
  底部一行网址。整段最后 0.4s 保持静止，不要淡出到黑。
- **为什么**：结尾只留一个动作；按钮是整片唯一的青铜实心块。
- **可调**：`brand`、`cta` 文案、`url`、`--halo`（柔光强度）、按钮宽度。
- **忌**：不要放二维码、不要放三个并列按钮、不要再讲功能。

## 5. 运动质量

- 帧率跟导出（默认 30fps）；镜头之间**硬切**，同一镜头内用 120 / 180 / 240ms 三档缓动（`cubic-bezier(.22,.61,.36,1)`）。
- 元素入场只用位移 + 透明度；不要旋转超过 6deg，不要弹跳（`back` 缓动只允许按钮一次）。
- 扫描光、进度条是「持续动作」，其余元素「进入后静止」。
- 一个镜头内最多两条独立动画同时发生；超过就说明该拆镜头了。

## 6. 声音

- 配乐：低频脉冲 + 轻打击（80–110 BPM），无旋律也行；在转场处给一个明确的落点。
- 音效一声一段：开场 whoosh、特写扫光的 shimmer、功能点亮的 tick、转场 band hit、结尾按钮 click。
- 旁白按画面段分开，一段一句；没有旁白时，让字幕承担信息。
- 混音：音乐压到旁白 0.36 倍，音效低通，避免盖住字。

## 7. 原生动作（按片子需要挑）

- **数字先行**：把最大的结果数字放在转场或 CTA 前，观众会自己补因果。
- **一条线贯穿**：开场扫描线可以延续成功能演示的进度条，再收进 CTA 按钮的描边。
- **同色只给一次**：整片只有一个青铜实心块（CTA 按钮）；其余青铜只出现在文字与 1px 描边上。
- **留白段落**：功能演示后给 0.5s 只有网格与光的空镜，让下一段有落点。

## 8. 常见问题

- 文案超过两行标题 + 一句 tagline：删，不是缩小字号。
- 产品画面靠 CSS 画不出可信度时：用用户自己的产品图，不要用 AI 生成的假产品。
- 每个镜头都想加动效：回到第 5 节，一个镜头两条动画封顶。
- 配色跑偏：只允许第 2 节表里的值；需要深浅变化时用透明度，不要引入新色相。
